# 🚀 API Testing with Postman + Newman

This project demonstrates automated API testing using Postman and Newman with the ReqRes API.

## 📌 Features

- ✅ GET - List Users
- ✅ POST - Create User
- ✅ PUT - Update User
- ✅ DELETE - Delete User
- 🔐 Auth - Login (Success & Failed)
- 🧪 Automated tests with Postman Scripts

## 🛠️ Tools Used

- Postman
- Newman (Node.js)
- ReqRes API
